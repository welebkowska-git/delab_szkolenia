# Motywacje szkoleniowe w gospodarce cyfrowej

Website developed for the report  
**„Motywacje szkoleniowe w gospodarce cyfrowej: Przekwalifikowanie i podnoszenie kwalifikacji jako odpowiedź na wyzwania zmieniającego się rynku pracy”**  
(DELab UW).

The website presents the full content of the report in an accessible, web-based format and includes **interactive data visualizations embedded directly within the site**.

## My role
I was responsible for:
- full website development and structure,
- implementation using MkDocs,
- visual design and layout customization,
- development and integration of **interactive Tableau visualizations embedded in the website**,
- content integration and deployment support.

The analytical content of the report was developed by the research team at DELab UW.  
My contribution focused on **web presentation, data visualization, and user-facing design**.

## Tech stack
- **Python** (MkDocs)
- **Markdown**
- **HTML / CSS / JavaScript**
- **Tableau** (interactive dashboards embedded in the site)
- MkDocs theme customization
- GitHub Pages (deployment)

## Project scope
- web-based version of a policy-oriented research report,
- structured navigation of report chapters,
- embedded interactive visualizations (Tableau),
- responsive design for desktop and mobile,
- download access to the full PDF report.
